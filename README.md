# Analisis_AndesCapitalRealEstate

## Andes Capital Real Estate — Análisis de Ventas y Clientes

Descripción del proyecto

Andes Capital Real Estate es un proyecto de análisis de datos desarrollado en Power BI, enfocado en comprender el desempeño comercial de una empresa del sector inmobiliario.

El análisis integra información de ventas, clientes, propiedades y canales de comercialización, con el objetivo de identificar patrones de comportamiento, evolución de las ventas y diferencias entre segmentos.

El proyecto combina preparación de datos, creación de indicadores y visualización interactiva para facilitar la exploración de la información.


**Objetivo**

Analizar el desempeño comercial de Andes Capital Real Estate y responder preguntas relacionadas con:

- ¿Cómo evolucionan las ventas durante el período analizado?

- ¿Qué tipos de propiedades generan mayor volumen de ventas?

- ¿Qué canales de comercialización concentran más ingresos?

- ¿Cómo se comportan los clientes compradores?

- ¿Qué proporción de clientes realiza compras recurrentes?

- ¿Cómo evolucionan las cohortes de clientes a lo largo del tiempo?

## Proceso de análisis


**1. Preparación de datos**


Se realizó la revisión y transformación de los datos para preparar la información para el análisis en Power BI.

Se trabajó en aspectos como:

Revisión de tipos de datos

Limpieza y transformación de variables

Preparación de fechas

Creación de una tabla calendario

Organización de las relaciones entre tablas





**2. Creación de KPIs**

Se construyeron indicadores para analizar:

Ventas

Propiedades vendidas

Clientes compradores

Clientes recurrentes

Comisión total

Ticket promedio

Crecimiento interanual

Tasa de recurrencia





**3. Análisis comercial**

El dashboard permite analizar las ventas según diferentes dimensiones:

Año

Ciudad

Tipo de propiedad

Canal de venta

Segmento de cliente





**4. Análisis de clientes y cohortes**

Se incorporó un análisis del comportamiento de los compradores, diferenciando entre clientes de una sola compra y clientes recurrentes.

También se utilizaron cohortes para observar la evolución de los clientes a través del tiempo y analizar la recurrencia de compra.





### Principales resultados

Durante el período analizado se identificaron los siguientes resultados:

Las ventas totales alcanzaron aproximadamente $6,01 millones.

Se observó un crecimiento interanual de 11,14%.

Se identificaron 3.189 clientes compradores.

2.421 clientes realizaron compras recurrentes, equivalente a una tasa de recurrencia de aproximadamente 77,13%.

Las propiedades tipo Casa representaron aproximadamente $2,24 millones en ventas.

El canal Corredor concentró aproximadamente $4,38 millones en ventas, frente a $1,63 millones del canal Directo.

Las propiedades Comerciales presentaron el mayor ticket promedio, cercano a $1,80 millones.

Estos resultados permiten observar diferencias en el desempeño comercial según tipo de propiedad, canal y comportamiento de los clientes.
